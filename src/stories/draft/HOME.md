# Queensland Government Design System - Bootstrap 5

The Queensland Government Design System (QGDS) Bootstrap 5 library is the official component library for Queensland Government websites and digital services.

## What is QGDS Bootstrap 5?

QGDS Bootstrap 5 provides production-ready, accessible UI components that:

- Implement the [QGDS UI Kit](https://www.figma.com/design/qKsxl3ogIlBp7dafgxXuCA/QGDS-UI-kit) design specification
- Extend Bootstrap 5.3 with Queensland Government branding
- Meet WCAG 2.1 Level AA accessibility standards
- Work with Handlebars templating for flexible server-side and client-side rendering

## Key Features

✅ **60+ Production-Ready Components** - Forms, navigation, content, layout, and media components  
✅ **Accessible by Default** - WCAG 2.1 AA compliant out of the box  
✅ **Template-Based** - Handlebars templates for easy integration  
✅ **Multi-Platform** - Works with Node.js, Express, static sites, and more  
✅ **Government Branded** - Official Queensland Government design tokens and theming

## What's Included

### Components

Forms - Buttons, inputs, selects, checkboxes, radio buttons, text areas
Navigation - Breadcrumbs, menus, pagination, side navigation
Content - Cards, accordions, tables, tabs, alerts, callouts
Layout - Headers, footers, containers, page templates
Media - Images, video players, icons

Utilities
Design Tokens - Colors, spacing, typography scales
Accessibility Tools - Focus styles, ARIA patterns, keyboard navigation
Theming - Multiple color palettes (default, light, alt, dark, dark-alt)
